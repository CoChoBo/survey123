# survey123

간호대 교수님께서 진행하시는 복지관 건강관리 프로그램에서
참여자 건강 점수를 확인하고 관리하기 위해 보조로 제작한 실습 프로젝트입니다.

## 프로젝트 목적
- 복지관 참여자 건강 설문 점수를 간단히 계산하고 기록
- 관리자 화면에서 기간별/이름별로 점수 확인
- 참여 추이 시각화로 상담/관리 참고 자료 제공

## 제가 도와드린 부분
- 설문 입력 페이지(`index.html`) 구성
- BMI 자동 계산 및 점수 반영 로직 구현
- 점수 저장/조회 API 연동 (Google Apps Script Web App)
- 관리자 페이지(`admin.html`) 조회 기능 구현
- 기간 조회
- 이름 검색
- 최근 참여자 조회
- 점수 추이 차트 표시
- 디버그 로그 영역 추가로 통신 오류 확인 쉽게 개선

## 파일 구성
- `index.html`: 참여자 설문 및 건강 점수 계산/저장
- `admin.html`: 관리자 조회/검색/시각화
- `README.md`: 프로젝트 설명

## 실행 방법
1. `index.html`을 브라우저에서 열어 설문 입력 테스트
2. `admin.html`을 브라우저에서 열어 관리자 조회 테스트

## 참고
- 수업/실습 기반으로 진행한 작업이며, 실제 현장 사용 흐름에 맞춰 필요한 기능을 우선 구현했습니다.
